# 🐺 狼人杀 · 多人联机模式

一个**和原命令行版完全分开**的联机版本：电脑开一个端口，其他人用**浏览器**就能加入。
真人不够时由 **AI 自动补位**，凑齐一桌。

> 代码位置：`net/server.py`（服务端）、`net/index.html`（网页客户端）。
> 它只复用原项目的纯逻辑（`game.py` / `ai.py` / `llm.py` / `config.py`），
> **不修改**原来的 `main.py` 命令行主程序，互不影响。

---

## 1. 启动服务端（房主的电脑）

```bash
cd /Users/hanks/Desktop/wolfKill

# 真实对局（默认免费模型 nvidia/nemotron-3-super-120b-a12b:free，不消耗额度）
python3 net/server.py

# 常用参数
python3 net/server.py --port 3000     # 指定端口（默认 3000）
python3 net/server.py --total 8       # 一桌总人数（真人+AI），4–12，默认 8
python3 net/server.py --mock          # 离线：AI 用确定性逻辑，不联网、不消耗额度（适合测试）
python3 net/server.py --model <slug>  # 换模型
```

启动后终端会打印两个地址，例如：

```
本机访问：   http://127.0.0.1:3000
局域网访问： http://192.168.1.23:3000   ← 把这个发给朋友
```

## 2. 玩家加入

- **房主自己**：浏览器打开 `http://127.0.0.1:3000`
- **同一 WiFi / 局域网的朋友**：浏览器打开房主的**局域网地址**（如 `http://192.168.1.23:3000`）
- 每人输入昵称 → 进入大厅 → **房主**点「开始游戏」（可先调整总人数）
- 真人不足总人数时，剩余席位由 AI 补齐；角色随机分配，只有你自己能看到你的身份。

## 3. 外网联机（不在同一局域网）——内网穿透

如果朋友不在同一个网络，用内网穿透把本地端口暴露成一个公网网址。任选其一：

### 方案 A：cloudflared（免费，无需注册，推荐）

```bash
# macOS 安装
brew install cloudflared

# 启动隧道（先确保 server.py 已在 8080 运行）
cloudflared tunnel --url http://localhost:3000
```

终端会给出一个形如 `https://xxxx-xxxx.trycloudflare.com` 的公网地址，发给朋友即可访问。

### 方案 B：ngrok（免费，需注册拿 token）

```bash
brew install ngrok            # 或到 https://ngrok.com 下载
ngrok config add-authtoken <你的token>
ngrok http 3000
```

复制它给出的 `https://xxxx.ngrok-free.app` 公网地址发给朋友。

### 方案 C：局域网直连（同公司/同宿舍/同 WiFi）

无需穿透，直接把终端打印的「局域网访问」地址发给朋友即可。
> 若朋友打不开：检查是否在同一网络；关闭房主电脑的防火墙对该端口的拦截；确认用的是 `http://` 而不是 `https://`。

## 4. 玩法说明

- **夜晚**：守卫守护 → 狼人（可与队友商量，可杀队友）→ 预言家查验 → 女巫用药 → 结算。
  这些机密只有对应身份本人看得到，其他人屏幕上不会显示。
- **🐺 狼队密谋室（同阵营讨论）**：只要有**真人狼人**，夜晚就会先打开一个「狼队密谋室」面板。
  所有狼人（真人 ↔ 真人、真人 ↔ AI）都能在里面自由聊天、互相反馈；AI 狼会实时回应你们的讨论。
  讨论结束后点「结束讨论，决定今晚刀谁」，再各自做出最终刀人选择（狼队多数决）。
  这个密谋室与外面的公共发言/投票**完全隔离**，好人那边看不到任何狼队对话。
- **白天**：轮流发言 → 投票放逐。投票时可以点「🙅 弃票」。
- 轮到你行动时，网页会弹出对应的按钮 / 输入框；没轮到你时会显示「等待其他玩家」。
- 掉线兜底：某位玩家超过 3 分钟不操作，系统会自动用默认选择（投票默认弃票），避免拖死整局。

## 5. 安全提示

这是给朋友娱乐用的轻量服务端，**没有做鉴权加固**。请只在可信的朋友之间使用，
不要把公网地址长期挂在不可信的互联网上。玩完 `Ctrl + C` 关闭服务即可。
