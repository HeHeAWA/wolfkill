📝 测试范围与说明

  • 测试方法：启动 WerewolfServer --mock，用 Python 通过 HTTP API 驱动；对局逻辑由确定性 mock-AI 执行，覆盖完整游戏循环（夜晚→白天发言→投票放逐→猎人/遗言→胜负判定）。
  • 真人对局路径：由「主机自动应答机器人」模拟真人提交（choice/女巫/发言/上警/狼队讨论等），验证 /api/action、/api/chat 各分支。
  • 挂机容错：场景 B 让房主全程不操作，验证 8 秒挂机跳过（IDLE_PASS）生效，对局仍可在 ~15s 内结束而非 45 秒超时堆积。
  • 前端特性：夜晚不亮框、输入不丢失、踢人按钮、clientId 幂等、AI 思考中为前端代码静态校验（需浏览器实跑确认视觉效果）。
  • LLM 直连：确认 LLM.java 移除代理逻辑走直连；OpenRouter 真实连通性受沙箱网络限制，需在部署环境自测。
  • 神职死亡停顿：静态确认预言家/女巫/守卫死亡后仍有 10 秒播报停顿（防时序泄密），且不会造成卡死。
  • 每场景独立重启服务器，杜绝跨场景状态污染（如大厅人数累积导致加入满员）。
