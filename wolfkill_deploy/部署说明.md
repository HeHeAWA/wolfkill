# 狼人杀 · 多人联机 — 服务器部署说明

适用于 **雨云游戏云 / 任意纯净 Linux 服务器**（仅依赖 Python 标准库，无需 pip 安装任何第三方包）。

---

## 一、目录里的文件

```
wolfkill_deploy/
├── server.py        # 联机服务端（HTTP 服务 + 游戏逻辑 + 网页托管）
├── index.html       # 玩家网页客户端（无需单独部署，由 server.py 直接提供）
├── config.py        # 配置（模型、API Key、开关）
├── game.py          # 游戏核心状态与规则
├── ai.py            # AI 决策（发言/投票/夜间行动）
├── llm.py           # 大模型调用（OpenRouter）
├── main.py          # 命令行单机版（可选，不在服务器上跑也没关系）
├── human.py         # 命令行真人交互（可选）
├── start.sh         # 后台启动脚本
├── stop.sh          # 停止脚本
├── requirements.txt # 依赖说明（标准库，空）
└── server.log       # 运行日志（启动后自动生成）
```

> **核心依赖关系**：`server.py` 会 import 同目录的 `config/game/ai`，`ai.py` 再 import `llm`。
> 所以这些 `.py` 必须和 `server.py` 放在**同一个目录**——本文件夹已经摆好，不要拆开。
> `index.html` 也必须和 `server.py` 同目录（网页由它直接托管）。

---

## 二、环境要求

- Python **3.7+**（用了 f-string、`http.server.ThreadingHTTPServer`、`secrets` 等标准库特性）。
- 服务器能联网（用于玩家访问 + 若用真实 AI 还需能访问 OpenRouter）。
- 一条命令检查：

```bash
python3 --version
```

若提示 command not found，先装 Python（Ubuntu/Debian：`sudo apt update && sudo apt install -y python3`；CentOS：`sudo yum install -y python3`）。

## 三、把文件传到服务器

任选一种：

1. **雨云面板文件管理**：在实例的「文件」/「文件管理」里新建 `wolfkill` 目录，把本文件夹内所有文件上传进去。
2. **SFTP**：用 FileZilla / Termius 连上服务器，把 `wolfkill_deploy/` 整个目录拖进去。
3. **宝塔面板**：文件管理里上传并解压。

传完后建议 `chmod +x start.sh stop.sh` 让脚本可执行。

## 四、启动服务

### 方式 A：直接前台运行（调试用，关掉终端即停止）
```bash
cd wolfkill_deploy
python3 server.py --port 3000
```

### 方式 B：后台运行（推荐，断开 SSH 也持续运行）
```bash
cd wolfkill_deploy
chmod +x start.sh stop.sh
./start.sh            # 默认 3000 端口，真实 AI 模式
# 或指定端口：   ./start.sh 8080
# 或离线模式：   ./start.sh 3000 --mock   （不调大模型，纯规则 AI，适合无网络/先试跑）
```
启动后日志写在 `server.log`，可 `tail -f server.log` 查看。

停止：` ./stop.sh `

### 方式 C：systemd 常驻（服务器重启自动拉起，进阶）
新建 `/etc/systemd/system/wolfkill.service`：
```ini
[Unit]
Description=WolfKill Online Server
After=network.target

[Service]
WorkingDirectory=/root/wolfkill_deploy
ExecStart=/usr/bin/python3 /root/wolfkill_deploy/server.py --port 3000
Restart=always
User=root

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now wolfkill
# 查看状态： sudo systemctl status wolfkill
```

## 五、放行端口（关键！否则外网打不开）

1. **雨云控制台 → 防火墙 / 安全组**：新增规则，放行 **TCP 3000**（或你自定义的端口）。
2. 若服务器本身开了 `iptables`/`ufw` 防火墙，也要放行：
   ```bash
   sudo ufw allow 3000/tcp      # 用 ufw 的情况
   ```
3. 云厂商的安全组优先级最高，**面板里没放行就绝对访问不了**，请务必确认。

## 六、玩家怎么进

- 浏览器打开：`http://<服务器公网IP>:3000`
  （公网 IP 在雨云实例详情页查看；若用了域名+反代，则填对应地址）
- 输入昵称 → 点「进入房间」即可。房间满员或房主点「开始」后进入游戏。
- 同一 WiFi / 同一台服务器的朋友用局域网 IP 也能进（启动日志里会打印「局域网访问」地址）。

## 七、AI 模式说明

| 启动方式 | AI 行为 |
|---------|--------|
| `./start.sh 3000` （不加 `--mock`） | 调用真实大模型（默认 `tencent/hy3:free`，免费、中文好），AI 会真正推理、对发言做出反应 |
| `./start.sh 3000 --mock` | 离线规则 AI，不发网络请求，跑流程快但不智能，适合先验证部署是否通 |

- 模型与 Key 在 `config.py` 里：`API_KEY`（已内置一个免费 key）、`MODEL`。
- 想换模型：`python3 server.py --port 3000 --model meta-llama/llama-3.3-70b-instruct:free`
- 免费模型有频率限制（429），频繁报错可换付费 key 或切 `--mock`。

## 八、常见问题

- **打不开网页**：先确认 ①服务器进程在跑（`ps aux | grep server.py`）②安全组/防火墙已放行该端口 ③用公网 IP 而非 127.0.0.1 给朋友。
- **端口被占用**：换端口（`./start.sh 8080`）或 `pkill -f server.py` 后重来。
- **Python 版本过低**：升级到 3.7+。
- **AI 一直不说话 / 报错**：多为网络无法访问 OpenRouter 或 key 限流，先 `--mock` 验证；联网正常再换真实模式。
- **日志查错**：`tail -f server.log`。
